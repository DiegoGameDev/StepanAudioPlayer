# Stepan Player

Um player de música em C# com sistema de playlists e interface baseada em padrões customizados.

---

## 🚀 Usar o programa

Se você só quer usar o Stepan Player, baixe aqui:

👉 https://github.com/DiegoGameDev/StepanAudioPlayer/releases/tag/v1.1

Não é necessário compilar o projeto.

---

## 💻 Sobre

O Stepan Player é um projeto focado em:

- Organização de músicas via playlists  
- Interface baseada em arquivos `.stp`  
- Estrutura simples e controlada no AppData  
- Execução leve e independente  

O projeto também serve como base de estudo para:

- Manipulação de arquivos  
- Estrutura de aplicações locais  
- Organização de código em C#  

---

## 📂 Estrutura

O programa cria automaticamente:

AppData/Roaming/Stepan/

- StepanPattern → arquivos de interface  
- StepanAudioPlayer → configurações  
- StepanPlayLists → dados de playlists
